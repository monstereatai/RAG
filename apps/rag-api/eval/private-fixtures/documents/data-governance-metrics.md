# 数据治理与指标口径规范

> 版本：1.5 | 生效：2026-01-01

## 一、核心指标口径

### 1.1 月活用户（MAU）
统计自然月内至少登录一次的去重用户，**不包含测试账号和内部压测账号**。

### 1.2 收入确认
- SaaS 订阅收入：按服务期间线性确认
- 专业服务收入：按交付里程碑确认
- 禁止提前确认未交付收入

### 1.3 客户留存率
- 月留存：当月活跃/上月活跃 × 100%
- 年留存：当年有付费记录/上年有付费记录 × 100%

## 二、数据质量要求

- 核心字段缺失率 < 1%
- 数据延迟不超过 15 分钟
- 指标定义变更需数据治理委员会审批
