尚武之魂觉醒四方
叶修
CV：张杰
曾临巅峰，亦经低谷。十年热爱，初心未改。
他是缔造三连冠王朝的斗神,也是风雪夜后白手起家的队长。三十七连胜,四次最有价值选手；离开嘉世后，他带着君莫笑从兴欣重新开始，最终再度登顶。或许，真正的荣耀从不只在巅峰，而在那份永不熄灭的热爱中。
甘璇
CV：张惠霖
穷极寰宇之理，运筹纤毫之间。
甘璇半生仰观星穹，录尽潮汐盈虚，却算出万物覆灭的终局。
既知天地不仁，她便以身入局，誓要作那对弈天道的变数。
巫真
CV：陆敏悦
无名无姓之人，混沌未分之气。她提弓魅影般独行世间，追寻过往，也探求去处。
巫通幽玄，真溯万物之本。林州灯火之中，她找到了那个名字。为护此灯长明，巫真愿再次背井离乡，直面裂隙深处——那幽暗残酷的过往。
以手中长弓，护佑此间，绝不许悲剧重蹈覆辙。
李寻欢
CV：凃雄飞
小李神刀，冠绝天下，出手一刀，例不虚发。
李寻欢的飞刀之所以天下无敌，真正原因不是后天努力和先天聪慧，乃是因为他有一颗伟大的心，才能练成这种伟大的武功。
万钧
CV：李洋
雷霆贯身，独行九州，万钧是江湖人口中的“惊世先生”；恪守道义，一诺千金，更是世上公认的“无极第一镖客”。济世利民之托，他慨然应允；快意恩仇之请，他亦不推拒。但凡应下此镖，纵使刀山火海，也在所不辞！
蓝梦
CV：墨筱晓
自幼流落街头的彩戏师蓝梦，很早就明白这世间道理——除了吃饭和活着，没什么值得放在心上，有几个靠认真工作发了财？
可惜江湖路远，麻烦不断。闲适如她，也被迫卷入纷争……
席拉
CV：谢莹
首席神愈者,晨曦圣女,席拉曾享尽月轮举国的赞誉与荣光。但如今美名已逝,只余非议与流言。
异端?疯癫?无所谓,光明在暗夜之中总会刺眼。为追寻那神圣的光辉,她甘愿奉献所有,矢志不渝。
张起灵
CV：北辰
是身怀长生之秘的张家族长，也是出尘绝世的无言麒麟。
张起灵背负家族使命，执着地穿梭于世间，寻找缺失的记忆，守护一切万物的终极。
刘炼
CV：孙恺寅
西北润州的百年炉火，炼出无数金石，亦孕育着刘家世代传承的白金之力。刘炼从不相信天赋异禀，他只知精金百炼，方可至臻。
魏轻
CV：唐雅菁
少入正法司，断狱清明，决事刚果。
后领命南下，寻踪觅迹，缉凶千里。
执金卫都统魏轻，誓要让真相昭然，水落石出。
哈迪
CV：刘照坤
哈迪·伊斯玛尔是月轮国有史以来最年轻的学者，他才思敏捷、心灵手巧。
如果没有发生那些事的话，他会早早的进入学宫，成为学者们敬仰的师长。
但是，命运之河还是将他带上了聚窟洲，去完成属于他的旅行。
玉玲珑
CV：蔡娜
狡黠善变，是融有天狐魂魄的倾世灵姿；通晓万物，是传自隐族通教的不宣之秘。
逃离狱岛和族人的束缚后，踏上寻欢作乐的救世之途的玉玲珑，于人间尚不知是福是祸……
季莹莹
CV：皛四白
天生异相，不详之女。
她是无常司最出色的鬼差，中州最可怖的传闻。
当她寻回自己名字时，来自幽冥的业火，将会焚尽一切曾背弃她的人。
胡为
CV：常文涛
入山寨，平山寨；从军行，又离军行。
喝虎奶长大的胡为，如林间野兽般自由。
能牵绊他那颗狂野之心的，只有云州的安危。
沈妙
CV：龟娘
此乃人妙手妙，才妙技妙之妙龄女子。
其造物精妙绝伦，其言行机智巧妙，其性情妙绝人寰！！！
与之为友，岂不妙哉，与之为敌，甚是不妙！
——沈妙
殷紫萍
CV：云鹤追
萍生泉动泽四方，曾助客枕梦黄粱。
问切已如花解语，吐息犹胜返魂香。
温婉灵动的少女状似柔弱，却在国仇家恨前果敢坚毅。
“救一人易，救天下人难……但紫萍愿意一试！”
武田信忠
CV：刘北辰
平生不思欲，凡事皆无悔。
即使吾被世人以不忠不义之名唾弃，也定不相负挚友所托。
若行至末路，便以手中之刃，尽斩身前障碍！
吾身可灭，吾道不可弃！
顾清寒
CV：钟可
在顾清寒的心中，她不是金枝玉叶的帝国公主，也非仙姿绰约的藏雨阁主人；她只是誓要雪葬仇敌的冰寒飞影，是殷切寻回至亲的飘零孤雁。
无尘
CV：李兰陵
行无常执，应时而发。即使血脉非正，魂魄不全，可无尘仍能凭借自己的力量成为隐族新任密使。他相信，万法不拘，才可破劫通玄。
季沧海
CV：刘以嘉
举杯痛饮，人生尽欢。烈豪这称号的背后，是他洒脱不羁的脾性，也是他遇强则强的豪情。纵然命运之路沉重难行，但他将依旧挥刀向前。
迦南
CV：杨梦露
风沙淬炼，让她迅捷如沙漠的黑鹰；古教秘传，又使其虚幻如古城的鬼魅。她是曼妙的刺客，也是权贵的梦魇。
宁红夜
CV：黄莺
西出昆仑的盲剑客，美丽危险的赤练蛇。对于宁红夜这样的强者而言，剧毒早已刻入血脉，利刃则永不离身边。而被遮蔽的双眼，将在宿命来临时再次凝视世界。
特木尔
CV：孟祥龙
苍狼的血脉再度长啸之时，草原上的风暴便会肆虐。先祖的传说刻在脑海，伟大的荣光就在眼前。来自草原上的狼，将再度狂奔。
土御门胡桃
CV：陶典
日轮之花，天才阴阳师，继承古老传承的大小姐。为了探寻天地秘密，掌握阴阳术的终极，胡桃离家出走，踏上了她新的旅程。
天海
CV：李元韬
云游天下，他终于找到心中答案——挽救世间，哪怕牺牲自己。雷霆之怒，化为嗔怒金刚，扫除一切业障，而拦路者，将承受无尽怒火。
妖刀姬
CV：张琦
没有人能躲下她的妖刀，刀下亡魂累累，平静下来后，她又会因伤害了太多人而自责。
有时候“强大”并不是一件好事，必须有承受和控制这份“强大”的能力才行。
崔三娘
CV：周帅
只叹造化弄人，本是将门之后的崔三娘飘零海外。但她胸怀大志、腹有良谋，是纵横捭阖的奇女子，更是广有神通的人中龙。为心中大义而战，称雄四海的她必将掀起滔天巨浪。
岳山
CV：梁达伟
北望中州，犹记起，去年行军。山川宁，海晏河清，笑语声声。海上巨涛玉州侵，云州霜刀漠北尘。风云起，四方戍边谁？披甲魂。
乾坤颠，少阳昏；朝纲倾，天柱沉。忌武成，忠岳一门幽困。抖擞金戈神兵降，千军辟易聚窟征。讨逆贼，匡扶社稷主，九州镇。

同源武器
千机伞
相传月轮有巧匠精于机括，见诸般兵刃繁重，携行多有不便，便以伞为形，以机关作骨，将百般锋芒藏于一柄之中。且千机伞开合无定，攻守相易，展开如骤雨飞花，收拢似游龙归袖。
飞刀
飞刀，自古流传的暗器翘楚。其形小巧锋利，携带便易。出手之瞬，犹如逐电追风，叫人防不胜防。
拳刃
拳刃古已有之，据说来自于平民中的好勇斗狠之辈。因为其快、准、狠、奇的特点，后多为月轮刺客所用。
双戟
双刀的同源武器
兼具力量和速度的双戟，出现于无极帝国仿佛是一种必然。因为它无论在军中或武林，都有着威猛、灵活的表现。
双刀
双戟的同源武器
不同的文明都有双手各持短刀的战法，可见双刀的出现是武道的必然。且双刀其势，大多均是疾疾如流星赶月，翩翩似穿花蝴蝶。
双节棍
双节棍在经历了千年的演变后，成为了今天的模样。施展起来华丽缭乱的双节棍，在尚武的无极帝国备受武人钟爱。
棍
枪的同源武器
棍号称“百兵之长”，是最早、也是习练人数较多的兵器。无极武人认为，枪便是脱胎于棍。
枪
棍的同源武器
枪号称“百兵之王”，因为其不仅攻击范围大，而且枪的招式大多迅捷灵活。
扇
匕首的同源武器
脱胎于短兵的扇，因其潇洒飘逸的招式而在无极武林的奇门兵器中占有一席之地。
匕首
扇的同源武器
“一寸短，一寸险”亮出匕首不仅仅代表了暗藏杀机的打法，更代表着舍身搏命的决绝。
横刀
太刀的同源武器
横刀是无极官兵的一种佩刀。其刀身笔直，中正不阿。既有剑的王者之风，又有刀的霸者之气。
太刀
横刀的同源武器
在无极帝国横刀传至日轮国后，经过日轮匠人数百年间的改良，逐渐演变成了现在日轮国的太刀。
阔刀
斩马刀的同源武器
阔刀是一种攻守兼备的武器，因其挥舞起来势如猛虎、颇具霸气而极受欢迎。
斩马刀
阔刀的同源武器
斩马刀柄长刀重，深受无极帝国将领喜爱，因其多用于战阵之中，上斩敌将，下斩战马而得名。
长剑
从远古时期就出现在战场上的近战兵器，因其携之轻便、佩之显贵、用之迅捷而被称为“百兵之君”。
链剑
链剑的形制介于长剑与软鞭之间，施展时刚柔并济，变幻莫测。其形随意转之妙，深合无极武人“以巧驭力”的哲思。
万刃轮
隐族工匠受到风车的启发而制成，其破坏力和金属刃片转动时的噪音都极为恐怖。
双铳
月轮国的工匠们将鸟铳改造成小巧的双持形制，使其既可凭借交替射击持续开火，亦可通过蓄力瞬间释放汹涌火力。
弓
从远古时期就出现在战场上的远程兵器，甚至无极帝国的“张”姓便是因为这种武器而得名。
火炮
得益于无极帝国军部对火器研发的投入，轻便且威力极大的单人手持火炮出现在了战场上。
连弩
据传说是一位无极帝国的先贤所制，能以疾风骤雨之势射出大量箭矢。
鸟铳
月轮国的工匠们改良了从无极帝国传入的火铳，加长了枪身、缩小了口径，使之射程及精准度都大幅提高。
喷火筒
隐族工匠制造的神器，将阴阳二气转换为焚尽万物的火焰。
五眼铳
隐族工匠从凡人火器中汲取灵感而制，因能从五根枪管中同时发射弹药而得名。
一窝蜂
隐族工匠制造的神器，以阴阳二气的力量一次性驱动发射数十发箭矢。
