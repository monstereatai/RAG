- 运营与活动：只抽取页面明确展示的活动、公告、版本、礼包或社区运营文案；未展示的规则标记为待确认。
- 营销素材：识别 Hero、PV、角色／玩法展示、新闻、FAQ、下载和转化入口。
- 工程验收：结合页面可见内容记录首屏、响应式、视频降级、地区语言、跳转和埋点待核项，不把推测写成事实。
