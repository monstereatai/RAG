## 参考答案（先做完再看）

1. **错**。fallback 是**人话降级语义声明**——给排障的人和运营面板看，说明该工具不可用时链路如何继续；不是可执行代码（§3.1）。
2. **对**。source 三值：builtin / mcp / external（§3.1）。
3. **对**。无 IO、无状态，注册表查找 + 内存比对——单测零 mock（§3.3）。
4. **B**。闸 1 fail-closed（§3.4）。
5. **B**。工具可用范围是产品决策，落在 modes 元数据（§3.2）。
6. **B**。从便宜到贵：内存查找 → 模式比对 → 白名单 → 角色；便宜的先拦下大多数请求（§3.3）。
7. 给排障的人和运营面板看。发挥价值的时刻：故障与降级发生时——运维看到"bocha_web_search 被降级"，fallback 一句话就知道**链路没断、证据从哪来**，不用读代码。它是"降级语义"的文档化：写代码的人被迫在注册时就想清楚"这工具挂了系统怎么办"。
8. 默认放行 + 日志：攻击者诱导模型调用未注册的 `rm_files`，工具真的执行了，日志只是事后尸检材料；默认拒绝：调用在闸 1 就死，攻击面根本不存在。**日志是观测，不是防御**——fail-closed 把防线从"事后追责"前移到"事前阻断"。
9. ① `execute` 不属于注册条目——注册表只有元数据，实现与注册分离（把函数塞进来说明没理解三层架构）；② risk: 'low' 配写入数据库的工具是错的——写操作至少 medium/high 且应 `requiresApproval: true`；③ permission 字段缺失（应为 'write'）；④ modes/timeoutMs/audit/fallback 全缺——审计开关没开会失去追溯能力；⑤ 没有 roles 限制意味着任何岗位都能写库。
