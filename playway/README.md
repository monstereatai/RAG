## 三、平台特征

从组件词汇可推断的系统能力：

- **多语言 / 多地区**：地区菜单、语言菜单、海外登录——国内 + 出海双场景
- **微信生态深度集成**：消息订阅、授权、红包提现、口令兑换
- **第三方 SaaS 接入**：智齿客服
- **强运营玩法**：付费分层、结伴充值、组队满员抽奖等
- **组件面板计数**：截图上 `(0/N)` 为面板计数，语义待确认（疑似"当前活动已用 0 个 / 分类可用 N 个"）

运行时规则注册表见 [`backend/src/modules/workflow/playway-component-registry.ts`](../backend/src/modules/workflow/playway-component-registry.ts)，覆盖截图中的 96 个组件，并为每个组件定义适用活动、前置依赖、产生事件、风险等级和合规要求。

## 四、与 RAG 项目的衔接

production workflow 的 `pageSchema`（页面结构 Schema）组件枚举可直接从本词汇表取材，让 LLM 生成的低代码 Schema 贴近真实营销中台的组件语义：

- **结构化组件清单**：[docs/reference/playway-component-inventory.md](../docs/reference/playway-component-inventory.md)——每个组件配英文 ID、说明、活动类型组合建议与 prompt 注入格式，`components[].type` 从中取值
- 活动类型 × 场景矩阵 → 工作流 brief 的结构化输入
- 课程 `course-agent/06-sop-workflow`（岗位协作）的素材引用

### 活动模板融合

运行时已内置 4 个可复用活动模板：新服预约、私域拉新、游戏促活、游戏回流。每个模板同时约束必选／可选组件、接口、埋点、验收规则和风险提示，工作流会依据 Brief 检索候选模板并注入岗位 Prompt；后台工作流详情页可展开查看模板内容。

工作流详情页还支持生成安全的 Playway 活动页预览，并将活动→组件→接口→埋点关系同步到 Neo4j（需要启用 GraphRAG）。
