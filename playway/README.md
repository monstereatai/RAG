# 游戏营销中台素材与组件说明

本目录归纳游戏营销活动玩法和组件素材。组件词汇来自早期低代码活动搭建平台的面板截图；活动链路的完整说明见[营销活动运营玩法梳理](./营销活动运营玩法梳理.md)。

## 活动类型

| 活动类型 | 适用场景 |
|---|---|
| 新服预约 | 新服务器开放前用户预约 |
| 私域拉新 | 社群、公众号用户拉新 |
| 游戏促活 | 提升存量用户活跃度 |
| 游戏回流 | 召回流失用户 |

## 组件词汇表

12 个组件面板分类及通用、页面框架组件共整理为 96 个条目。完整名称、英文 ID、说明、活动组合建议和 Prompt 注入格式以[组件清单](../docs/reference/playway-component-inventory.md)为准；本文件不重复维护组件名称。

## 与 RAG 项目的衔接

- `pageSchema` 的组件枚举以组件清单为产品语义来源。
- 运行时注册表位于 [`playway-component-registry.ts`](../apps/rag-api/src/modules/workflow/playway-component-registry.ts)，为组件定义活动适用范围、依赖、事件、风险等级和合规要求。
- 工作流内置新服预约、私域拉新、游戏促活和游戏回流四类活动模板，并支持活动页预览及活动、组件、接口、埋点关系同步到 Neo4j。
