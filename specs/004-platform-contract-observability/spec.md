# 统一接口与问答运行协议

## 目标

统一 RAG、admin-backend、admin 的响应解包和问答运行状态；保留引用与思考详情；降低旧数据兼容散落和安全降级的误解。

## 验收标准

- AC-01：普通 JSON 接口经过 admin-backend 到前端只解包一次，不出现嵌套 `data`。
- AC-02：Simple、Auto、Agentic 输出统一的模型、路由、检索、证据和生成状态。
- AC-03：刷新并恢复历史会话后，引用、模型、路由、检索原因和思考事件仍可见。
- AC-04：网页端引用、文档详情、错误和空态均有可验证的 E2E 覆盖。
- AC-05：系统能力问题可直接回答；证据不足、模型失败、联网不可用显示不同原因。

## 非目标

本次不改数据库 schema，不修改模型供应商 Key，不重写 RAG 检索算法。
