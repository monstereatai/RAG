# 文档上传链路接通

## 问题

管理后台上传按钮没有文件选择事件，后台接口也以空 JSON 调用 RAG，导致 PDF 及其他文档无法上传。

## 目标

支持管理后台选择单个或多个文件，以 multipart 贯通 Admin → RAG Backend，并复用现有解析入库能力。

## 验收

- 上传按钮打开文件选择器并支持批量选择。
- 不手动设置 multipart Content-Type，文件可被 RAG Backend 解析。
- 支持 RAG 已声明的文档、图片、音频、视频扩展名。
- 上传成功刷新列表，失败给出提示。
- 列表按创建时间倒序展示最新文档。
- 大文件解析和索引使用独立长超时，避免被普通 API 超时误判失败。
