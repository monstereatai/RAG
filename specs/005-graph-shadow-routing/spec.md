# 图谱旁路探测与按需证据合并

## 目标

在统一混合检索主链路中并行执行受限的 Neo4j 图谱旁路探测，普通事实问题保持 BM25／向量主结果，关系、多跳、依赖和影响分析问题才将图谱事实合并为上下文证据。

## 非目标

- 不更换 Milvus 主向量库。
- 不让 Neo4j 替代 RRF、Rerank 或上下文预算门禁。
- 不新增数据库表、迁移、依赖或前端独立页面。

## 验收标准

- AC-01：图谱旁路探测有独立超时和结果上限，失败或超时不阻塞混合检索。
- AC-02：普通 lookup／procedure 问题的最终上下文不包含图谱事实，但诊断可记录探测状态。
- AC-03：关系、多跳、依赖、影响分析问题可将图谱事实以受治理 Chunk 合并到上下文，并保留来源文档 ID。
- AC-04：图谱查询跳过答案生成阶段，避免旁路探测额外调用 LLM 生成答案。
- AC-05：Backend 构建、相关单测或定向验证、Diff 检查通过；ROADMAP 和验证记录同步。

## 风险与边界

- 图谱服务未启用、用户身份缺失、权限策略拒绝、超时或异常时，主链路继续返回混合检索结果。
- 图谱证据受最终上下文预算、去重和文档上限约束，不绕过现有证据门禁。
