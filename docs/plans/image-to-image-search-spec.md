# 图片以图搜图 Spec

## 背景与目标

- 背景：项目已有图片资产索引与文搜图，但管理端不能上传图片作为查询。
- 目标：管理员上传一张图片，检索当前身份有权访问的相似图片资产。
- 成功标准：图片上传、向量检索、权限过滤和结果预览代理完整贯通；现有文搜图继续可用。

## 范围

- 包含：管理端以图搜图入口；Admin Backend 上传代理；RAG Backend 图片 embedding 检索；用户、租户、角色和文档 ACL 过滤；5 MB 上传上限及定向测试。
- 不包含：新增模型或依赖、数据库 schema 变更、查询图片持久化、图片入库流程调整、生产部署。

## 验收标准

### AC-01：管理员可以用图片检索图片

- 前置条件：图片向量索引和多模态 embedding 已配置。
- 操作：在管理端选择图片并搜索。
- 预期结果：使用图片向量检索 `rag_images`，结果显示相似图片及相似度。
- 验证方式：ImageIndexService、RagAdminService、管理端代理定向测试和前端 build。

### AC-02：结果遵守当前身份的权限范围

- 操作：使用图片查询。
- 预期结果：用户、租户、角色由已验证登录态派生，结果仅包含当前可访问且生效的文档图片。
- 验证方式：服务与控制器测试断言调用上下文和 ACL 过滤。

### AC-03：上传请求受限且查询图不留存

- 操作：上传大于 5 MB 或非图片文件，或执行正常图片查询。
- 预期结果：超限或非图片请求被拒绝；正常查询仅用于 embedding，不写入图片索引。
- 验证方式：控制器校验测试、上传限制配置和 ImageIndexService 检索实现。

### AC-04：现有文搜图保持可用

- 操作：继续通过文字描述搜索图片。
- 预期结果：原 GET 检索路由及页面入口保留。
- 验证方式：既有管理端代理和 RAG 控制器定向测试、前端 build。

## 边界与约束

- 图片上传限制：5 MB；管理端和 RAG 端各自校验。
- 用户身份上下文由 Admin Backend 登录态派生，不接受浏览器提交的身份字段。
- 图片检索复用现有多模态 embedding、Milvus 图片集合和生效文档 ACL。
- 不改数据库、环境变量、依赖或部署配置。
- 未做真实 embedding 供应商联调。
