# 安全策略与数据生命周期边界

## 安全策略版本化

策略目录由 `listSafetyPolicies()` 输出，包含 `version`、`enabled` 和 `effectiveAt`。每次规则变更必须提升版本并记录变更原因、误拦截样本、灰度范围和回滚版本；生产环境切换由发布流程控制，禁止直接改运行中的正则。

## 审计与运行数据

| 数据 | 默认保留 | 脱敏要求 | 删除边界 |
| --- | --- | --- | --- |
| 安全拦截事件 | 180 天 | 只保存 query hash，不保存原文 | 到期由运维任务按租户清理 |
| 问答质量日志 | 180 天 | 用户标识按权限展示 | 仅保留聚合指标用于趋势 |
| Agent 运行事件 | 90 天 | payload 不得含密钥和原始凭据 | 运行结束后按租户归档 |
| Artifact | 30 天或业务配置 | 下载链接短期有效 | 到期撤销分享并清理对象存储 |

删除、导出和保留期限调整必须生成审计记录；当前仓库提供查询与脱敏展示，真实定时清理需要部署侧调度器和备份策略配合。

## 文档完整性

文档入库记录 `contentSha256`、来源和版本链；重复内容只产生告警，不覆盖已有文档。索引重建保留原 `docId`、生命周期、审核字段和 ACL，并返回差异校验结果。修复失败不得标记为成功，运营页应依据结果重试。

## 运营闭环

质量、安全、索引、任务和 Agent 运营数据均遵循「发现 → 查看脱敏详情 → 重试/修复 → 处理状态 → 审计留痕」链路。对接真实清理任务、工单和告警通道属于线上环境工作，不在本地仓库中伪造完成。
