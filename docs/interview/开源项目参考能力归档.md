# 开源项目参考能力归档

> 记录 Dify、RAGFlow、AutoGPT、MetaGPT、CrewAI、AutoGen、DeepSeek Harness、WeKnora 对当前项目的可参考能力、实际融合结果和明确边界。
>
> 当前项目：企业智能知识库与游戏官网／活动营销 Agentic RAG 平台。
>
> 记录原则：只记录已经结合当前 NestJS + React + LangGraph.js + Milvus + Elasticsearch／BM25 + Redis + Neo4j + MCP 架构落地，或明确标记为待生产接入的内容，不把外部项目能力直接照搬成“已实现”。

## 一、总体结论

当前项目没有引入上述项目的第二套运行时，而是吸收其产品设计和工程思想，统一落到现有链路：

```text
Dify              → 平台治理、模型／工具／工作流版本、评测集、运营看板
RAGFlow           → 知识库治理、解析切块、混合检索、检索调试、引用追溯
AutoGPT           → Agent Run、Action、成本、审批、重试、模板复用、运行中心
MetaGPT           → 角色 SOP、结构化交接、Artifact 依赖、冲突决策、项目回放
CrewAI            → Task、Process、Sequential／Hierarchical／Conditional 编排
AutoGen           → 运行事件、消息流、Agent as Tool、工具预算、多 Agent 指标
DeepSeek Harness  → 目标生命周期、请求快照、上下文压缩审计、统一工具执行、结果外置、事件回放
                          ↓
             LangGraph + Redis Checkpointer + Agent Ops
                          ↓
          RAG 问答、方案生成、运营审计、持续回归闭环
```

### 已形成的统一闭环

1. 用户提问或管理员启动产研运工作流。
2. 系统根据 Simple／Auto／Agentic 路由执行检索、生成或多 Agent 编排。
3. 每个 Agent、Task、Tool、Artifact、交接消息和审批动作都有结构化记录。
4. 低质量回答可以提交 Bad Case，经过审核、回灌、重新召回和回归验证。
5. Agent Ops 可以查看运行中心、调用链路、事件流、任务看板、Artifact、冲突决策和项目回放。
6. LangFuse 记录 Trace／Generation，Prometheus 记录运行指标，平台治理负责模型、工具、知识库和评测集配置。
7. 长会话压缩、目标状态、请求快照、工具审批与结果外置也进入统一运行事件，支持按 Run 回放。

## 十、统一状态流转

```text
用户问题／管理员工作流
  → 路由：simple／auto／agentic
  → Run 创建：步骤、工具、委派、成本预算
  → 检索：关键词、语义、图谱、融合、重排、权限过滤
  → Agent Task：角色、依赖、SOP、交接、Artifact
  → Tool：MCP／内部工具、风险检查、动作审计
  → 审批：高风险动作、产物、冲突和 Bad Case
  → 回答／结构化交付物
  → LangFuse Trace + Prometheus 指标 + 运行事件
  → 用户反馈／Bad Case
  → 审核 → 回灌 → 重新召回 → 评测回归
```

### 本项目当前可主张的差异化

1. 游戏活动和官网营销的业务元数据、规则版本、生效期、地区与岗位范围可直接进入检索过滤。
2. 六岗位 Agent 工作流能把需求整理成可审批、可恢复、可局部重跑的结构化交付物，并通过 MCP 交接给编码 Agent。
3. RAG 回答链路强调来源权限、生命周期、引用证据、拒答与 Bad Case 回归；索引侧有多存储对账和持久修复队列。
4. 项目级公开游戏资料和仿真问题集为该垂直场景提供回归入口；这些数据不是公司私有业务数据，也不能证明真实线上准确率。

### 比较边界

- WeKnora 版本基准为官方 v0.8.3（2026-10-14）；本节对其功能依据官方 README 和 CHANGELOG，未在本机部署运行 WeKnora。
- 当前项目工作区含未提交代码改动；本节描述当前工作树和仓库文档，不等同于已发布版本。
- 当前工作树中的 Feishu 凭据和线上同步未验证；全局飞书应用凭据的 RAG tenant 信任白名单不等于租户或知识空间隔离，首版仅支持新版 docx。Team Wiki 与 Feishu 迁移已应用到当前本地 PostgreSQL；图片真实模型效果待测；隔离 Redis 实例取消任务与清理联调通过，处理中任务不可中断。以上实现状态不代表生产就绪。
- 当前项目的成熟度分数、仿真评测和本地索引验收不能与 WeKnora 的评测结果直接横向比较；真实业务准确率、生产 SLA、规模性能和完整多租户隔离仍需目标环境验证。
