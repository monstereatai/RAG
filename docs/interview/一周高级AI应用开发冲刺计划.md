# 一周高级 AI 应用开发冲刺计划（个人可选复习路线）

两门课程按完整能力设计，不受七天限制。本文件只是已有后端经验、已拥有当前 RAG（检索增强生成）项目时的复习安排；全课以 [课程指南](../../course/GUIDE.md) 和两份结业验收为准。

## 个人七天安排

每天可投入 8～10 小时，包含阅读、编码、调试与复盘。遇到未通过的关键能力继续练习，不为赶进度跳过验收。

| 天数 | 对应新模块 | 当天证据 |
| --- | --- | --- |
| 1 | AI 应用模块 1～3：架构、模型调用、入库 | 画链路；跑结构化输出与切片练习 |
| 2 | AI 应用模块 4：检索、融合与重排 | 四组检索对照，固定数据与候选数量 |
| 3 | AI 应用模块 5：三模式与证据门禁 | 三类问题的路由、补证与引用记录 |
| 4 | AI 应用模块 6～8：治理、评测与交付 | 用户隔离与依赖降级记录 |
| 5 | Agent 模块 1～3：任务、工具与幂等 | 权限阻断、串行／并发重复与未知结果 |
| 6 | Agent 模块 4～6：规划、循环、审批与协作 | 预算实验、生产工作流审批与修订记录 |
| 7 | Agent 模块 7～8：任务评测与运行治理 | 一次独立小变更、回归与项目答辩 |

这只是时间分配建议，未完成内容延续到后续学习。MCP（模型上下文协议）在 Agent 工具模块学习，不必在最后一天重新开发外部工具。

## 验收与已有项目

使用当前项目，不另建结业系统。按 [AI 应用结业验收](../../course/CAPSTONE.md) 与 [Agent 结业验收](../../course-agent/CAPSTONE.md) 独立操作、修改、排障和解释取舍。

最终材料：链路图、质量对照报告、正常与异常运行记录、小需求变更与回归、项目口述稿。已存在功能和别人生成的代码不能代替个人验收。

## 部署与经验积累

已有服务器和配置就绪时，可按 1～2 天安排现有系统部署与核心验证；约一周可集中整理运行证据，实际以结果为准。长期运营经验随持续使用积累，没有必须等待 2～3 个月才能上线或参加面试的要求。

当前课程审阅发现的 Chat（问答）审批与循环快照边界见 [实现校正](../../course/IMPLEMENTATION-NOTES.md)。不能把这些待验证或已知有缺口的路径写成全部已可靠恢复。
