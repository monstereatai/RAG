# ADR-001：确定性流程采用 Workflow First

- 状态：accepted
- 日期：2026-08-03
- 影响范围：六岗位产研协作 Agent、审批、局部重跑

## 背景

产品、设计、前端、后端、测试、运营之间存在明确依赖、责任边界和上线门禁。若完全交给 ReAct 自由规划，角色顺序、审批和终止条件会随模型波动，难以复现与审计。

## 备选方案

1. 纯 Chain：稳定且便宜，但不能处理节点内部的不确定任务。
2. 纯 ReAct／Tool Use：探索能力强，但路径、成本和终止不稳定。
3. Workflow First：DAG 管依赖和门禁，节点内部允许模型推理和工具调用。

## 决策

采用 Workflow First。执行批次由代码计算，重要岗位按风险触发审批，普通任务自动流转；单岗位可以独立执行，多岗位按 DAG 协作；节点内部用结构化 LLM 和白名单工具完成专业任务。

## 代价

新增流程建模、状态持久化和局部重跑复杂度；业务流程变化需要维护 DAG。它换来的是可预测路径、失败隔离、审计和稳定回放。

## 验证指标

工作流成功率、模型成功率、角色完成率、审批就绪率、证据覆盖率、P95、人工接管率、循环终止原因。工作流降级完成不得计入模型成功。

## 回滚条件

若任务路径本身长期未知、DAG 维护成本超过人工规划收益，改为“Planner 生成计划＋人工确认＋受限执行”，而不是直接放开无限 ReAct。
