# 架构决策记录

这里记录会影响系统质量、稳定性和演进成本的关键决策。每份 ADR 都必须说明背景、备选方案、选择理由、代价、验证指标和回滚条件，不能只写“采用某技术”。

| ADR | 决策 |
| --- | --- |
| ADR-001 | 确定性产研流程采用 Workflow First，节点内使用 Agent 推理 |
| ADR-002 | 采用多路召回、RRF 融合与条件式 Rerank |
| ADR-003 | 采用证据充分性、Claim 引用校验和拒答门禁 |
| ADR-004 | 区分会话历史、短期记忆、长期记忆和长期知识 |
| ADR-005 | 外部模型与工具采用预算、超时、降级和恢复验证 |

状态定义：`accepted` 表示当前执行方案；指标持续不达标或回滚条件触发时，新建 ADR 取代旧决策，不覆盖历史理由。
