# ADR-003：证据门禁、Claim 引用校验和拒答

- 状态：accepted
- 日期：2026-08-03
- 影响范围：RAG 回答、引用、版本冲突与低相关拒答

## 背景

检索到文本不等于文本能支撑答案。企业知识问答的风险不是“没说得很漂亮”，而是数字、时间、活动规则和接口结论没有可靠出处，或旧版本与新版本混在一起。

## 备选方案

1. 仅依赖 Prompt 要求引用：实现简单，但模型仍可能生成不存在的引用。
2. 只看整体相似度：无法判断每个事实是否被证据支撑。
3. 检索充分性＋Claim 级支撑＋引用校验＋拒答／冲突提示。

## 决策

生成前判断检索是否充分；生成后把关键事实拆成 Claim，校验其关键词和来源片段；引用必须能回到真实片段；证据不足时拒答或明确待确认；检测到版本冲突时展示冲突和生效信息，不静默选择。

## 代价

回答会更保守，部分“看起来能答”的问题会被拒绝；Claim 校验增加一次计算和规则维护。该代价符合企业场景“宁可不答，也不编”的目标。

## 验证指标

Faithfulness、Claim 支撑率、引用正确率、引用完整率、拒答准确率、冲突处理率、无答案集误答率，以及答案完整度。

## 回滚条件

若拒答率过高，先分析切片、召回和阈值，不直接关闭门禁；只有在明确低风险场景下，允许切换为“提示不确定性后回答”。
