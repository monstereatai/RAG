# ADR-005：外部依赖预算、超时、降级和恢复验证

- 状态：accepted
- 日期：2026-08-03
- 影响范围：LLM、Rerank、Web Search、Milvus、Redis、GraphRAG

## 背景

Agent 链路比普通接口包含更多外部依赖。任何一个模型、工具或存储超时都可能放大总耗时、触发重复调用甚至形成死循环。单次 smoke 成功不能证明长期稳定。

## 备选方案

1. 无限重试：偶发错误恢复率高，但会放大成本和雪崩。
2. 立即失败：简单，但用户任务不可用。
3. 分层预算＋有限重试＋可解释降级＋Checkpointer 恢复。

## 决策

每个节点设置超时、重试次数和工具预算；总工作流有步骤和时间上限；Rerank／Web／Graph 失败可回退到本地证据，向量检索失败可回退 BM25／ES；关键写操作不做静默降级；Checkpointer 支持中断后恢复；指标分开统计成功、降级和错误。

## 代价

降级答案可能质量下降，超时阈值过紧会误伤慢请求，过松又拖长尾延迟。阈值必须由重复回放和生产分位数校准。

## 验证指标

依赖成功率、降级率、P50／P95／P99、重试放大倍数、工具成功率、工作流成功率、模型成功率、恢复时间、重复副作用次数。

## 回滚条件

降级结果低于最低质量门槛时改为明确失败和人工接管；重试放大导致错误率或成本上升时收紧预算并启用熔断。
