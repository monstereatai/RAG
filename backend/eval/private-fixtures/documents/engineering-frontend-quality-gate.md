# 前端质量门禁规范

> 版本：1.8 | 生效日期：2026-02-15 | 责任部门：前端架构组

## 一、构建门禁

- TypeScript 不允许新增 error。
- Lint warning 不阻断灰度，但新增 warning 必须登记来源。
- 核心页面首屏 JS 体积超过 350KB 需拆包说明。

## 二、体验门禁

| 指标 | 阈值 | 处理 |
|------|------|------|
| LCP | <= 2.5s | 超出需优化图片/拆包 |
| INP | <= 200ms | 超出需定位长任务 |
| CLS | <= 0.1 | 超出需固定尺寸 |

## 三、回归要求

- 管理后台表格必须覆盖空态、加载态、错误态。
- 文档/问答/图谱页面不得出现横向溢出。
- 涉及音频播放、流式输出、导出下载的功能必须有可见状态反馈。
