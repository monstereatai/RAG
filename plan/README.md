# 未来功能计划目录

本目录记录尚未实现或尚未排期的产品功能计划，不作为项目实际进度的判定来源。

## 目录约定

- `future-features.md`：当前已提出的未来功能总计划，记录目标、分期、依赖、验收条件和待确认事项。
- 单项功能形成独立实施方案后，使用 `NNN-kebab-case.md` 命名，例如 `001-workflow-artifacts.md`。
- 每份计划必须标注状态：`待确认`、`待排期`、`进行中` 或 `已完成`；“已完成”只能在实现和验证完成后标记。
- 计划至少包含目标、范围、阶段、外部依赖、验收条件和未决问题；未知信息写“待确认”。
- 项目真实进度仍以根目录 `ROADMAP.md` 为准。功能实现或验证进展需要同步回该文件。
