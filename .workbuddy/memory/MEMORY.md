# 项目长期记忆 — 企业级 RAG

## 目录约定

- `docs/` 是**正式文档树**（架构、PRD、计划、面试材料），改动受项目规范约束。
- `ds/` 是**个人分析目录**，用于存放对项目的架构/机制分析笔记，不参与正式文档门禁。
  - 约定对标 `/Users/monster/Documents/GitHub/code/deepseek-harness/ds/`：文件名用英文、正文用中文、一篇分析聚焦一个主题、只记录「当前状态 + 结论」不写变更历史、过时直接更新或删除。
  - 目前已有：`ds/rag-retrieval-layers.md`（检索链路 9 层 L0–L8 分层详解）。

## 归档习惯

- 用户习惯把跨项目的深度分析笔记收进各自的 `ds/` 目录，而不是散落在 `docs/` 或临时文件里。
- 分析要求：结论必须带 `文件:行号` 级代码证据，拒绝表面化功能总结。
